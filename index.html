Welcome to Smart Health

Exploring the synergy of technology and healthcare through simulated analytics and modern design.

Case Study

A simulation-based approach to smart health monitoring and real-time data visualisation.

Background

With rising interest in digital health solutions, we set out to create a real-time dashboard that simulates vital signs and presents them using clean, interactive web interfaces. Our goal was to build a project that bridges engineering with applied health science.

Problem

Most existing dashboards were either overly technical or lacked visual accessibility. We wanted to address this gap by creating something simple, responsive, and aesthetically pleasing that both engineers and health researchers could collaborate on.

Solution

Using HTML, CSS, and JavaScript with Chart.js, we simulated three key metrics—Heart Rate, SpO₂, and Temperature—updating live every few seconds. The user interface features dark mode, responsive cards, data export functionality, and condition-based alerts.

Results

The final dashboard is deployable via GitHub Pages and performs smoothly across devices. It’s now being used as a showcase for portfolio, internship, and freelance opportunities in both tech and health sectors.
